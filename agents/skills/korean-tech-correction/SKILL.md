# 한국어 기술 문서 교정 스킬

기존 한국어 기술 문서의 톤/어체를 교정할 때 적용한다. 내용(사실, 수치, 코드, 로그)은 바꾸지 않고 톤과 표현만 교정한다.

## 톤 규칙

korean-tech-writing 스킬과 동일한 톤 규칙을 따른다. (`/mnt/skills/user/korean-tech-writing/SKILL.md` 참조)

핵심만 요약하면:

- 1인칭 서술체로 통일
- 부정-대비 구조("A가 아니라 B", "~라고 볼 수는 없습니다") → 판단한 내용을 바로 서술
- 분석 보고서 어투("핵심 증거입니다", "같은 결론을 지지합니다") → 관찰한 것을 직접 서술
- 과장/추상 비유("최종 승자", "붕괴", "surviving") → 실제 현상을 직접 서술
- 메타 프레이밍, 교훈 정리, 방어적 부정 → 삭제
- 대체 가능한 영어 → 한국어, 정착된 기술 용어는 유지
- 영어 직역투("동결", "닫힌", "의미론") → 자연스러운 한국어("확정", "통과한", "동작")

## 교정 시 주의

- 정독한 뒤 한번에 교정한다. 부분 패치를 반복하지 않는다.
- 기술적 사실(수치, 로그, 코드, 경로, 날짜)은 절대 바꾸지 않는다
- 정착된 기술 용어를 억지로 한국어로 바꾸지 않는다
- 교정 이유를 길게 설명하지 않는다. 바꾼 포인트만 간결하게 정리
