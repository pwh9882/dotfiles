# Triage Labels

Engineering skill이 사용하는 다섯 triage 역할을 GitHub label과 동일한 이름으로 매핑합니다.

| Skill 역할 | GitHub label | 적용 조건 |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer가 범위와 우선순위를 판단해야 함 |
| `needs-info` | `needs-info` | Reporter의 재현 정보나 선택을 기다림 |
| `ready-for-agent` | `ready-for-agent` | 범위, 완료 조건, 검증 방법이 있어 agent가 추가 질문 없이 진행 가능 |
| `ready-for-human` | `ready-for-human` | 사람의 판단·권한·물리 작업이 구현에 필요함 |
| `wontfix` | `wontfix` | 근거를 기록하고 작업하지 않기로 결정함 |

Skill이 역할 이름으로 label을 요청하면 이 표의 GitHub label을 사용합니다. 저장소 label 이름을 바꿀 때는 오른쪽 열과 GitHub 설정을 함께 갱신합니다.
